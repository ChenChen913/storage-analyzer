# Everything vs WizTree 同机对比（Windows）

> 测试日期：2026-10-23
> 测试目的：为 scan.py 的数据源选择与「用户该装哪一个」提供实测依据。

## 1. 测试环境与方法

| 项目 | 值 |
|------|----|
| 系统 | Windows 11，NTFS 系统盘 |
| 磁盘 | 单块系统盘，百万级文件 |
| Everything | es.exe 1.1.0.18，主程序运行中，已建全盘索引 |
| WizTree | 4.33，安装在默认目录 |
| 权限 | 普通用户（非管理员），WizTree 使用 `/admin=0` |
| 方法 | 同一台机器、同一块盘、顺序执行；先导出 CSV，再统计文件数/总字节，最后跑完整 scan.py |

说明：
- Everything 的耗时依赖已建好的常驻索引，不含首次安装后的索引构建时间。
- WizTree 每次都重新读盘，表中同时给出冷缓存首跑和热缓存复跑。
- 两边的总字节都是逻辑大小，会高于 `disk_used`（压缩、稀疏文件等），只用于两者相对比较。

## 2. 导出与覆盖对比

| 指标 | Everything | WizTree（/admin=0） | 差异 |
|------|-----------|--------------------|------|
| 导出耗时（冷） | 秒级 | 数十秒到数分钟 | Everything 快一个数量级 |
| 导出耗时（热） | 秒级 | 数十秒 | Everything 快数倍 |
| 文件行数 | 基准 | 少 2%~3% | 差额集中在受保护目录 |
| 逻辑总字节 | 基准 | 少约一成 | 同上 |
| 归一化额外耗时 | 无 | 数秒 | 仅 WizTree 需要 |
| 端到端 scan.py | 十几秒 | 一分多钟 | Everything 快约 5 倍 |

WizTree 非管理员模式漏掉的主要目录：

| 目录 | 漏报内容 |
|------|---------|
| `C:\Program Files\WindowsApps` | 应用本体整体缺失 |
| `C:\ProgramData\Microsoft\Windows Defender\...\Customizations` | 病毒库定义 |
| Windows 容器 GUID 目录 | 部分容器数据 |
| `C:\Windows\OEM`、`SystemTemp`、`ServiceProfiles`、`Prefetch` 等 | 零散系统目录 |

原因：`/admin=0` 下 WizTree 拿不到受保护目录的读取权限；Everything 的索引服务以系统权限读 MFT，所以能覆盖这些位置。管理员模式（`/admin=1`）预期能补齐，但本机当前会话未提权，未做实测。

## 3. 资源占用对比

| 指标 | Everything | WizTree |
|------|-----------|---------|
| 安装体积 | 约 3 MB | 约 20 MB |
| 空闲时常驻 | 有，百万级索引时数百 MB 内存 | 无常驻进程 |
| 每次扫描成本 | 读常驻索引，秒级 | 重新读盘，数十秒到数分钟 |
| 数据新鲜度 | 依赖索引实时更新，主程序未运行就不可用 | 每次都是当前状态 |
| 权限要求 | 无需管理员即可全盘覆盖 | 普通权限有覆盖缺口；完整覆盖需管理员 |
| 授权 | 免费 | 个人免费，商用需授权 |

## 4. 优劣总结

**Everything 的优势**
- 全盘覆盖完整，普通权限就能看到 WindowsApps、Defender 定义等受保护目录。
- 建好索引后每次分析近乎零成本，适合反复多轮分析。
- 安装体积小，命令行 `es.exe` 输出稳定，CSV 解析简单。
- 免费，商用也没有授权顾虑。

**Everything 的不足**
- 需要主程序常驻，百万级索引时占用数百 MB 内存，低内存机器要权衡。
- 主程序没运行时会报 `Error 8: IPC window not found`，需要先启动。
- 首次安装要花时间建索引。

**WizTree 的优势**
- 不需要常驻服务，空闲时零资源占用。
- 有成熟的图形界面，手动查看大树很直观。
- 安装即用，不依赖后台索引是否在跑。
- 安装体积约 20 MB，仍属轻量。

**WizTree 的不足**
- 普通权限下会漏掉约一成逻辑总量，集中在 WindowsApps 等受保护目录，会直接影响「应用本体占多少」的判断。
- 每次扫描都要重新读盘，热缓存数十秒，冷缓存可达数分钟。
- 完整覆盖需要管理员权限，`--wiztree-admin` 要在已提权的终端里跑。
- 商用需授权。

## 5. 推荐

**优先级从高到低：**

1. **已经装了哪一个，就用哪一个。** scan.py 的 `--source auto` 已经按「Everything → WizTree → walk」自动选择，不需要用户做决定。
2. **两个都没装，推荐先装 Everything。** 理由是全盘覆盖不需要提权、重复扫描秒级、安装包只有约 3 MB，最适合本 skill 这种要反复看全盘、还要审计 WindowsApps 的场景。
3. **以下情况改选 WizTree：** 机器内存紧张，不希望常驻数百 MB；只需要偶尔看一次；喜欢图形界面。此时请在提权终端里加 `--wiztree-admin`，否则会漏掉受保护目录。
4. 两个都没有、又暂时不想装：scan.py 会回退 `walk` 全盘遍历，能出结果，但百万文件级要几十分钟，只适合应急。

**给用户的一句话：**

> 推荐先装 Everything，免费、不用管理员权限就能看全盘，装好后每轮分析只要十几秒。WizTree 适合不想常驻后台、偶尔手动看磁盘的情况，但它默认权限会漏掉 WindowsApps 等系统目录，需要以管理员身份运行才完整。
